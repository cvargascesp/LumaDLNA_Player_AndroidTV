# Luma · Conexión

Icono elegido: tres nodos y enlaces formando un símbolo de reproducción.
Menta `#67E8CA`, azul hielo `#C8ECFF`, fondo azul noche `#0B1421`.

- `luma-connection.svg`: fuente vectorial editable y vista previa cuadrada.
- `ic_luma_foreground.xml`: símbolo dentro de la zona segura de iconos adaptativos.
- `mipmap-anydpi-v26/ic_launcher.xml`: icono adaptativo (Android 8+).
- `mipmap-anydpi-v33/ic_launcher.xml`: añade capa monocromática para iconos temáticos.
- `drawable/banner.xml`: banner Android TV 16:9 con símbolo y nombre LUMA en trazados.

Los recursos son vectoriales y se reconstruyeron a partir de la propuesta 03 para que se vean nítidos a cualquier densidad. El banner y el icono usan recursos separados; el launcher aplica su propia máscara al icono adaptativo.
